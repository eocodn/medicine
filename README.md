# 약봄

약봄은 나와 가족의 복용약을 한 기기에서 관리하고, 식품의약품안전처 공개 DUR 정보를 바탕으로
복용 전 확인이 필요한 금기·주의사항을 함께 보여주는 Android 앱입니다.

약봄의 DUR 결과는 **확인을 돕는 안전 신호**입니다. 앱의 결과만으로 약을 중단하거나 용량·복용법을
바꾸지 말고, 궁금하거나 경고가 표시되면 의사 또는 약사와 확인해 주세요.

## 주요 기능

- 나와 가족의 프로필을 한 기기에서 따로 관리
- 식약처 허가 의약품 검색 및 복용약 등록
- 사진의 글자를 기기에서 인식해 식약처 제품 목록에 대응하는 약품명 후보 검색
- 1회 복용량, 하루 횟수, 복용 시간, 식사 관계, 투여 경로, 복용 기간 기록
- 오늘 먹을 약 확인 및 복용 완료·건너뜀 기록
- 필요할 때 복용하는 약(PRN) 기록
- 병용금기, 특정연령대금기, 임부금기, 노인주의, 효능군중복주의 등 지원 범위의 DUR 확인
- 지원되는 경우 용량·투여기간 기준 확인
- 처방 변경 이력과 과거 복용 기록 보존

## 설치

현재 배포판은 다음 기기를 지원합니다.

- Android 9 이상
- `arm64-v8a` 기기

Android System WebView 또는 Google Chrome이 오래된 경우 앱 실행 전에 업데이트 안내가 표시될 수 있습니다.
안내가 표시되면 해당 구성요소를 최신 버전으로 업데이트한 뒤 약봄을 다시 실행하세요.

[GitHub Releases](https://github.com/eocodn/medicine/releases)에서 최신 버전의 다음 형식 APK를 받아 설치하세요.

`medicine-vX.Y.Z-arm64-v8a.apk`

Google Play가 아닌 APK 직접 설치 방식이므로, Android가 브라우저나 파일 앱에 대해
**알 수 없는 앱 설치 허용**을 요청할 수 있습니다. APK를 받은 앱에 한해 설치를 허용한 뒤 설치하면 됩니다.
원한다면 설치 후 해당 권한을 다시 끌 수 있습니다.

## 첫 실행

처음 실행할 때 약품 기준 데이터를 내려받아 검증한 뒤 앱을 사용할 수 있습니다.

- 첫 실행 시 인터넷 연결이 필요합니다.
- 현재 데이터 크기를 고려해 **약 300MB 이상의 여유 저장공간**을 권장합니다.
- 실제 필요한 공간은 약품 데이터 업데이트에 따라 달라질 수 있으며, 앱이 설치 전에 필요한 여유 공간을 확인합니다.
- 다운로드가 중단되면 앱에서 다시 시도할 수 있습니다.

약품 기준 데이터 설치가 끝난 뒤에는 저장된 데이터를 사용해 앱을 시작할 수 있습니다.

## 업데이트

GitHub에서 직접 설치한 APK는 **자동 업데이트되지 않습니다**.

새 버전이 나오면 GitHub Releases에서 새 APK를 내려받아 기존 약봄 위에 설치하세요. 정상적인 정식 배포판끼리는
기존 앱을 삭제하지 않고 업데이트하는 방식으로 개인 복약 기록을 유지할 수 있습니다.

아주 초기의 테스트용 약봄 APK를 설치했던 기기는 정식 배포판으로 바로 덮어쓸 수 없을 수 있습니다.
이 경우 기존 앱을 삭제한 뒤 새 APK를 설치해야 하며, **앱을 삭제하면 기기에 저장된 개인 복약 데이터도 삭제될 수 있습니다.**
기존 앱 삭제 안내가 표시된다면 중요한 기록을 먼저 확인해 주세요.

## 다운로드 파일 확인

각 GitHub Release에는 APK와 함께 다음 파일이 제공됩니다.

- `SHA256SUMS`: 내려받은 파일이 배포된 파일과 같은지 확인하기 위한 SHA-256 체크섬
- `THIRD_PARTY_NOTICES.txt`: 앱에 포함된 오픈소스 구성요소의 저작권·라이선스 고지

파일 무결성을 직접 확인하고 싶다면 `SHA256SUMS`에 적힌 APK의 SHA-256 값과 내려받은 APK의 값을 비교하세요.

## 개인정보와 네트워크 사용

등록한 프로필, 복용약, 복용 일정과 기록 등 개인 복약 데이터는 기기 내부의 앱 전용 저장소에 보관됩니다.
Android에서는 해당 개인 데이터의 지속 저장본을 기기 보안 기능을 이용해 암호화합니다.

인터넷 연결은 최신 약품 기준 데이터를 내려받는 데 사용됩니다. 약봄은 별도 계정이나 클라우드 동기화를
제공하지 않으므로 여러 기기 사이에서 개인 복약 기록이 자동으로 공유되지 않습니다.

앱을 삭제하면 Android가 약봄의 로컬 앱 데이터를 함께 삭제할 수 있으므로, 삭제 후 재설치가 필요한 경우에 유의하세요.

## DUR 결과를 볼 때 꼭 알아둘 점

`DUR 주의사항 없음`은 **모든 의학적 위험이 없다는 뜻이 아닙니다.** 약봄은 앱이 가진 데이터와 지원하는
판정 범위 안에서 확인할 수 있는 항목만 평가합니다.

현재 자동 확인에 포함되지 않거나 충분히 판단할 수 없는 정보에는 다음과 같은 내용이 있을 수 있습니다.

- 알레르기
- 신장·간 기능
- 체중과 적응증
- 앱에 등록하지 않은 일반의약품
- 건강기능식품이나 기타 복용 제품
- 앱이 구조적으로 판정할 수 없는 조건부 DUR 기준

앱이 `자동 확인 범위 제한`, `판정 불가`, 금기 또는 주의 경고를 표시한다면 안전하다고 추측하지 말고
의사 또는 약사에게 현재 복용 중인 약과 함께 확인해 주세요.

응급 증상이 있거나 심각한 이상반응이 의심되면 약봄의 결과를 기다리지 말고 즉시 적절한 의료기관이나
응급의료 서비스를 이용하세요.
